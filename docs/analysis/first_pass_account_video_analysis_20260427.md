## 2. 跨账号共性结论

### 2.1 更容易出正反馈的内容结构

1. **问题型开头更强**  
   典型句式：`你知道...吗`、`怎么...`、`到底...`、`为什么...`、`千万别再...`。  
   这类标题天然制造信息差，适合语文/英语知识短视频。

2. **冷知识 + 学科知识结合更强**  
   语文账号里，`冷知识`、`汉字`、`成语`、`传统文化`、`生僻字`、`动物雅称`表现更好。  
   英语账号里，`英语口语`、`英语单词`、`自然拼读`、`剑桥英语`、`KET/PET`更容易形成明确人群。

3. **可收藏/可转发素材强于泛节日内容**  
   Top 视频多是可沉淀知识点、答题技巧、作文素材；Bottom 中更常见泛春节/拜年/生活记录，和账号学习定位弱相关。

4. **“真实课堂/老师问答”适合 IP 号**  
   子琦老师这类账号中，`下课后我问老师...`、课堂随拍、老师答疑型内容更容易被识别为真实教学场景。

5. **体系化规划适合组织/课程导向账号**  
   紫一/剑桥类账号里，`剑桥体系`、`KET/PET`、`备考三步`、`学习规划`更适合承接课程意图。

## 4. 如果给一个新视频，第一版适配判断规则

### 语文 IP 号

更适合：

- 明确小学生/家长痛点：作文开头、阅读理解、修辞判断、成语积累。
- 口播第一句有问题：`这句话到底是不是比喻？`、`作文没话写怎么办？`
- 内容能被收藏：口诀、公式、模板、分类表。

不适合：

- 只有泛生活记录。
- 节日祝福但没有知识点。
- 标题没有具体对象，只说“这个画面怎么写”。

### 语文组织/规划号

更适合：

- 成语、美词佳句、传统文化、国风表达。
- 可以形成系列：一天一个成语、一个典故、一句高级表达。

不适合：

- 过强 IP 日常但没有知识承接。

### 英语 IP 号

更适合：

- 口语替代表达：别再说 rain / sorry / flower。
- 趣味记忆：动物、缩写、发音反差。
- 老师背景或真实经历增强可信度。

不适合：

- 单纯语法讲解且没有钩子。
- 标题太像教材目录。

### 剑桥/体系号

更适合：

- 家长决策问题：新概念 vs 剑桥、KET/PET 备考、学习路径。
- “三步搞定”“怎么选”“黄金期”等规划型表达。

不适合：

- 泛单词技巧，没有剑桥体系关联。
